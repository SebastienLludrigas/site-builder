# Creator

Develop a web application that enables non-technical users to build fully functional websites.

The application displays previously created websites; users can browse them, edit them, or create a new one.

All websites are hosted locally by the application itself; there is no remote deployment.

The website editor must be highly flexible, handling text, images, and interactive features, while remaining intuitive and simple to use.

The application must include several example showcase websites that can be designed and edited with the tool, highlighting the full range of its capabilities.

You have total freedom in designing the architecture and UX of the project.

Work autonomously. Do not stop until the product is complete, tested, and demo-ready, including all example showcase websites.
