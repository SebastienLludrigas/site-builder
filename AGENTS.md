# Creator

Développe une application web qui permet à un utilisateur non technique de créer des sites web entièrement fonctionnels.

L'application affiche les sites déjà créés ; l'utilisateur peut les consulter, les modifier ou en créer un nouveau.

Tous les sites sont hébergés localement par l'application elle-même ; il n'y a aucun déploiement à distance.

L'éditeur de site doit être très flexible, gérer le texte, les images ainsi que quelques fonctionnalités, tout en restant simple d'utilisation.

L'application doit inclure plusieurs exemples de sites pouvant être conçus et modifiés avec l'outil, mettant en valeur l'étendue de ses capacités.

Tu as une liberté totale sur la façon de concevoir le projet.

Travaille de manière autonome. Ne t'arrête pas tant que le produit n'est pas terminé, testé et prêt pour une démonstration, tous les sites d'exemple inclus.
